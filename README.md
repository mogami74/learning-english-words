# 英単語学習アプリ

シンプな英単語学習Webアプリケーション。
単元毎に子どもが学校から出される課題（小テスト）を勉強できるよう、フォルダごとに異なる単語リストで練習できるようになっています。

## 🚀 使い方

### 単語リストの準備

#### ファイルの配備場所

単語リストのJSONファイルは以下の場所に配置してください：

```
units/
  unit1/
    wordlist.json    # Unit 1の単語リスト
  unit2/
    wordlist.json    # Unit 2の単語リスト
```

#### JSONファイルの形式

各ユニットの `wordlist.json` は以下の形式で作成してください：

```json
[
  {
      "id": 1,
      "japanese": "……を呼ぶ",
      "english": "call",
      "difficulty": 1
  },
  {
    "japanese": "愛する",
    "english": "love",
    "difficulty": 1
  },
  {
    "japanese": "考える",
    "english": "think",
    "difficulty": 1
  }
]
```

difficultyは、表示される頻度を調整する整数です。大きな値にするほど表示頻度が上がります。
QAモード (日→英学習)で、「覚えた」ボタンを押すと-1されます。
difficulty=0の時に「覚えた」ボタンが「以後表示しない」ボタンに変化し、difficulty=-1になります。
difficult=-1の単語は、問題として表示されません。

**重要**: difficulty の変更は、wordlist.json ファイルに直接保存されます。Express.js サーバーが起動している場合、変更は永続化されます。

### サーバー起動方法
```bash
# Express.js サーバーを起動（ポート3001）
npm run server

# Webpack開発サーバーを起動（ポート8080）
npm run webpack:dev

# 両方を同時起動
npm run start:full
```



#### CSVからJSONへの変換

CSVファイルから簡単にJSONファイルを作成できます：

1. **CSVファイルの準備**
   ```csv
   呼ぶ,call
   愛する,love
   考える,think
   ```

2. **変換スクリプトの実行**
   ```bash
   node scripts/convert_csv_to_json.js
   ```

3. **生成されたJSONファイルを適切な場所に移動**
   ```bash
   mv wordlist.json units/unit1/
   ```

#### 注意事項
- ファイル名は必ず `wordlist.json` にしてください
- JSONの形式（特にダブルクォートの使用）を正確に守ってください
- 日本語の文字化けを防ぐため、UTF-8エンコーディングで保存してください

### 1. アプリの起動
1. ブラウザでアプリを開きます
2. トップページから学習したいユニットを選択

### 2. 学習モード

#### 📝 QAモード (日→英学習)
- **「QA」ボタン**をクリック
- 日本語が表示されます
- **クリック**すると英語が表示されます
- 自分のペースで学習を進められます

#### 📖 QQモード (日本語確認)
- **「QQ」ボタン**をクリック
- 日本語のみが表示されます
- 英語を思い浮かべる練習に最適

#### 📊 単語リスト表示
- **「単語リスト」ボタン**をクリック
- 全単語を一覧表で確認
- difficulty値と学習ステータスを表示
- 難易度フィルターと検索機能付き

### 3. ナビゲーション
- **「戻る」ボタン**: トップページに戻る
- **ブラウザの更新**: 新しい単語順序でリスタート

## 📚 収録単語

### Unit 1: 基礎英単語 (100語)
- **動詞**: call, love, think, make など
- **名詞**: lesson, class, teacher, friend など
- **代名詞**: our, they, yourself など
- **接続詞・前置詞**: but, so, about, with など
- **その他**: often, very, really, today など

## 💡 学習のコツ

### 効果的な使い方
1. **QAモード**で日→英の変換練習
2. **QQモード**で日本語から英語を想起
3. 分からない単語は繰り返し練習
4. 毎日少しずつ継続学習

### おすすめ学習パターン
```
1日目: QAモード 20-30語
2日目: QQモード 前日の復習 + 新規10-20語
3日目: QAモード 全体復習
```
